Connect your Firebase project

To enable accounts and cross-device sync, this tracker needs a free Firebase project. Setup takes about five minutes.

  1. 1
    Create a Firebase project
    Go to console.firebase.google.com → Add project. Skip Google Analytics.
  2. 2
    Enable Email/Password auth
    Authentication → Get started → Email/Password → toggle Enable → Save.
  3. 3
    Create a Firestore database
    Firestore Database → Create database → Production mode → pick a region close to you. Then go to the Rules tab and paste in the contents of firestore.rules.
  4. 4
    Add your site to authorized domains
    Authentication → Settings → Authorized domains → add your GitHub Pages domain (e.g. username.github.io).
  5. 5
    Copy your config into the app
    Project settings → General → scroll down → Add app → Web. Copy the six firebaseConfig values into firebase-config.js and push to GitHub.
